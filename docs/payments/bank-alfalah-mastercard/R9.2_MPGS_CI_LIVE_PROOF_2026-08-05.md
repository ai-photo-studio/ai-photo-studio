`{"error":{"cause":"INVALID_REQUEST","explanation":"Invalid credentials."},"result":"ERROR"}`;
this run's `401` status and header shape (`content-type=application/json;charset=ISO-8859-1`,
no `WWW-Authenticate`, no correlation id) is consistent with that same rejection pattern,
but is not itself proof of the exact body text this time.
